# Sakura Swap

Swap, liquidity, pools, token locker & portfolio untuk token Sakura Launchpad di Loop Network.

## Fitur

- **Swap** — beli/jual semua token yang sudah lulus (SAKURA, MESIAH, GANGEL, SGL2, SFSL) lewat Uniswap V2, dengan slippage dan price impact
- **Liquidity** — tambah & tarik LP
- **Pools** — semua pool dengan harga live dari cadangan on-chain
- **Locker** — kunci token supaya pembeli merasa aman (kontrak: `0xA4C46795Bc6116e0286ea13e1439622E9727B50f`)
- **Portfolio** — holdings, nilai, dan posisi LP

Mode terang/gelap, responsif di HP dan desktop.

SAKURA hanyalah token meme untuk testing, bukan token asli platform. Swap ini generik untuk semua token launchpad.
